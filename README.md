# Grok sanal masa

Bitget’e emir gitmez.

```
6 indikatör, 5 dakikada bir, ~100+ parite
        ↓
6 puan ve üstü 6-7 coin aday olur
        ↓
Grok kendi yorumunu yapar
        ↓
“Bu işleme giriyorum” veya “bekle”
        ↓
Defter + Telegram + ekran
        ↓
5 dk fiyat takibi · Grok’un SL/TP’sinde kapanış
```

İndikatörler: RSI, MACD, hacim, Bollinger, VuManChu Cipher B, PVG.

Tarama 5 dakikada bir. Grok düşünmesi saatlik. Arada Grok’un yazdığı SL/TP otomatik işler.

Telegram için Actions secrets: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.

Ekran: https://kuti4545.github.io/grok-paper-desk/
